# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| `0.1.x` | :white_check_mark: |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, report them privately via [GitHub Security Advisories](https://github.com/hapheus/honed/security/advisories/new).

Please include:
- A description of the vulnerability and its potential impact
- Steps to reproduce or a minimal proof of concept
- Affected versions and environment details

You can expect an initial acknowledgement within **48 hours** and a remediation plan or status update within **7 days**.
