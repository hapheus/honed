## [0.1.0] - 2026-11-22

### Added
- Initial release of **Honed** (`honed`): quality-first engineering skill for AI coding agents.
- Core commands: `init`, `audit`, `simplify`, `architect`, `refactor`, `harden`, `optimize`, `test`, `observe`, `productionize`, `deslop`, `polish`, and `doctor`.
- Deterministic multi-language detector (`honed detect`) for TypeScript/JavaScript, Python, PHP, Go, and generic cross-language rules with terminal, JSON, GitHub Actions, and SARIF 2.1.0 output.
- Multi-provider installer (`npx honed install`), `pin`/`unpin`, and edit-hook integration.
- Hardened GitHub OSS repository setup with CI, CodeQL, OSV-Scanner, OpenSSF Scorecard, and Dependabot.
